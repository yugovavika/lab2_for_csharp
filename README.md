# Задание 1

## Задача 1

### Текст задачи

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:
- Клеопатра
- Пушкин Александр Сергеевич
- Маяковский Владимир

Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения

1. Создан класс `Name` с тремя приватными полями: `firstName`, `surname`, `patronymic`.
2. Реализованы три конструктора:
   - `Name(string firstName)` — только личное имя;
   - `Name(string firstName, string surname)` — имя и фамилия;
   - `Name(string firstName, string surname, string patronymic)` — все три параметра.
3. Реализованы свойства `FirstName`, `Surname`, `Patronymic` для доступа к полям.
4. Метод `ToString()` последовательно проверяет каждое поле: если оно не `null`, не пустое и не состоит из пробелов — добавляет его в результирующую строку. В конце вызывается `Trim()` для удаления лишних пробелов.

## Задача 2

### Текст задачи

Создайте сущность Человек, которая описывается:
- Имя: строка
- Рост: целое число

Может возвращать текстовое представление вида "Name, рост: height", где Name и height это переменная с именем и ростом.

Необходимо создать и вывести на экран следующих людей:
- Человек с именем "Клеопатра" и ростом 152
- Человек с именем "Пушкин" и ростом 167
- Человек с именем "Владимир" и ростом 189

### Алгоритм решения

1. Создан класс `Person` с полями `name` (строка) и `height` (целое число).
2. В свойствах `Name` и `Height` реализована проверка на корректность:
   - `Name`: если пустое или `null` — выводится ошибка, запрашивается повторный ввод;
   - `Height`: если ≤ 0 или ≥ 300 — выводится ошибка, запрашивается повторный ввод.
3. Метод `ToString()` возвращает строку вида "Name, рост: height".
4. Ввод данных с клавиатуры организован через класс `Checked` с проверкой на положительное целое число.

# Задание 2

## Задача 1

### Текст задачи

Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: "Имя работает в отделе Название, начальник которого Имя". В случае если сотрудник является руководителем отдела, то текстовая форма должна быть "Имя начальник отдела Название".

Необходимо выполнить следующие задачи:
1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен оказаться один и тот же отдел и начальник).

### Алгоритм решения

1. Создан класс `Department` с полями:
   - `title` — название отдела;
   - `boss` — начальник (ссылка на `Employee`);
   - `employees` — динамический массив сотрудников;
   - `count` — текущее количество сотрудников.
2. Метод `AddEmployee` добавляет сотрудника в массив, при необходимости расширяя его вдвое.
3. Создан класс `Employee` с полями `name` и `department`.
4. В конструкторе `Employee` сотрудник автоматически добавляется в отдел через `department.AddEmployee(this)`.
5. Метод `ToString()` проверяет, является ли сотрудник начальником отдела (`department.Boss == this`):
   - если да — выводит "Имя начальник отдела Название";
   - если нет — выводит "Имя работает в отделе Название, начальник которого Имя".

# Задание 5

## Задача 1

### Текст задачи

Создайте сущность Пистолет, которая описывается следующим образом:
- Имеет Количество патронов (целое число)
- Может быть создан с указанием начального количества патронов
- Может быть создан без указания начального количества патронов, в этом случае он изначально заряжен пятью патронами.
- Может Стрелять, что приводит к выводу на экран текста "Бах!" в том случае, если количество патронов больше нуля, иначе делает "Клац!". После каждого выстрела (когда вывелся "Бах!") количество патронов уменьшается на один.

Создайте пистолет с тремя патронами и выстрелите из него пять раз.

### Алгоритм решения

1. Создан класс `Pistol` с полем `patrons` (целое число).
2. Реализованы два конструктора:
   - `Pistol()` — по умолчанию 5 патронов;
   - `Pistol(int patrons)` — с проверкой на неотрицательность.
3. Свойство `Patrons` имеет проверку: если значение < 0 — выводится ошибка, запрашивается повторный ввод.
4. Метод `Shoot()`:
   - если `patrons > 0` — выводит "Бах!" и уменьшает счётчик на 1;
   - иначе — выводит "Клац!".
5. Метод `ToString()` возвращает строку "Пистолет, патронов: N".
6. В `ProgramLab2.cs` создаётся пистолет с 3 патронами и производится 5 выстрелов, а также демонстрируется пистолет по умолчанию (5 патронов).
